# 定制默认桌面布局（预置图标/快捷方式）

本篇主要指导如何在 Android 10 原生桌面（Launcher3）上预置常用 App 的图标位置，调整底部快捷栏（Hotseat）图标，以及讲解如何快速验证。

---

### 一、 核心概念与配置选择

#### 1. 桌面网格布局（3x3 / 4x4 / 5x5）的区别与选择机制
*   **布局区别**：桌面图标是以网格排列的。`default_workspace_3x3.xml`、`default_workspace_4x4.xml` 和 `default_workspace_5x5.xml` 分别对应 3x3、4x4、5x5 网格的桌面默认布局。
*   **网格自动选择机制与核心类**：
    *   **核心类说明**：
        *   `com.android.launcher3.InvariantDeviceProfile`：网格匹配和加载的入口核心类。解析 `device_profiles.xml` 并动态匹配当前屏幕的网格大小。
        *   `com.android.launcher3.util.DefaultDisplay`：负责从系统底层获取当前物理屏幕属性（包括 DPI 像素密度、`realSize` 实际尺寸等）。
        *   `com.android.launcher3.DeviceProfile`：存放当前选定网格在特定方向（横/竖屏）下的具体 UI 参数（如图标大小、文字大小、内边距等）。
    *   **自动测量过程**：
        Launcher 启动时，`InvariantDeviceProfile` 通过 `DefaultDisplay` 读取屏幕的真实像素物理宽高，并结合 DisplayMetrics 通过 `Utilities.dpiFromPx()` 换算得出该设备在长边和短边方向上的 dp 尺寸，即设备的 `minWidthDps` 与 `minHeightDps`。
    *   **自动选择匹配逻辑**：
        1. 解析 `/packages/apps/Launcher3/res/xml/device_profiles.xml`，加载全部声明的 `<grid-option>`（如 3x3、4x4、5x5）及其中定义的 `<display-option>` 适配标准值。
        2. 遍历这些选项，使用欧氏距离算法（`Math.hypot(x1 - x0, y1 - y0)`）计算屏幕实际 dp 尺寸与各个配置项中定义规格的“几何距离”。
        3. **自动选取几何距离最近（差异最小）的那组配置**。因为本产品测量出的 dp 大小与 5x5 配置中最契合，所以自动选中了 `5_by_5` 网格，并加载了其对应的 `defaultLayoutId` 布局文件（即 `@xml/default_workspace_5x5`）。
*   **修改与强制配置方法**：
    *   **仅修改内容**：若已确认当前设备匹配 5x5，直接编辑对应的 `packages/apps/Launcher3/res/xml/default_workspace_5x5.xml` 即可。
    *   **强制指定网格**：如果你希望在所有不同尺寸的屏幕上强制应用 5x5 布局，可以将 `device_profiles.xml` 中所有其他网格的 `launcher:defaultLayoutId` 统一修改指向为 `@xml/default_workspace_5x5`，或者在对应的网格选项内直接修改其行列数（`numRows`/`numColumns`）。

#### 2. Launcher3QuickStep 与 Launcher3 的区别与配置选择
*   **区别**：
    *   **Launcher3**：传统的标准桌面，只负责桌面图标和应用抽屉展示。
    *   **Launcher3QuickStep**：增强版桌面，集成了 Android 9/10 全面屏手势动画以及最近任务管理器（Recent Apps）。
*   **如何查看当前编译配置**：
    *   在板级 Makefile（如 `device/rockchip/rk3399/rk3399_roc_pc_plus/rk3399_roc_pc_plus.mk` 或 `device/rockchip/common/device.mk`）中搜索 `PRODUCT_PACKAGES` 变量。
    *   若包含 `PRODUCT_PACKAGES += Launcher3QuickStep`，则系统使用的是带手势的桌面；若为 `Launcher3`，则是基础桌面。Android 10 默认使用 `Launcher3QuickStep`。
*   **修改当前配置**：
    *   如果需要裁剪手势，可以将其在 `PRODUCT_PACKAGES` 中替换为 `Launcher3`。

### 二、 完整开发与预置步骤

#### 步骤 1：修改默认布局配置文件
打开配置文件：`/packages/apps/Launcher3/res/xml/default_workspace_5x5.xml`。

*   **添加特定 App 的图标位置**：在 `<favorites>` 根标签中添加 `<favorite>` 标签：
    ```xml
    <favorite
        launcher:screen="0"
        launcher:x="1"
        launcher:y="1"
        launcher:packageName="com.jianbao.doctor"
        launcher:className="com.jianbao.doctor.activity.splash.NewSplashActivity" />
    ```
    *属性说明*：
    *   `launcher:screen`：代表放置在第几屏（从 0 开始）。
    *   `launcher:x` 和 `launcher:y`：代表在 5x5 网格中的横纵坐标位置（左上角为 0,0）。
    *   `launcher:packageName`：App 的包名。
    *   `launcher:className`：App 的启动 Activity 全路径类名。

*   **配置默认意图图标（例如默认浏览器）**：使用 `<resolve>` 标签：
    ```xml
    <resolve
        launcher:screen="0"
        launcher:x="2"
        launcher:y="2">
        <intent launcher:action="android.intent.action.VIEW" launcher:data="http://www.google.com" />
    </resolve>
    ```

*   **修改底部常驻快捷栏（Hotseat）**：
    将 `launcher:container="-101"` 的节点（如浏览器或相机）修改为您预期的应用或意图（`x` 的值代表左右摆放顺序）：
    ```xml
    <resolve
        launcher:container="-101"
        launcher:screen="4"
        launcher:x="4"
        launcher:y="0" >
        <favorite launcher:uri="#Intent;action=android.intent.action.MAIN;category=android.intent.category.LAUNCHER;launchFlags=0x10200000;component=com.android.settings/.Settings;end" />
    </resolve>
    ```

#### 步骤 2：编译 Launcher 模块
在源码根目录下执行单模块编译：
```bash
# 1. 导入环境变量
source build/envsetup.sh

# 2. 选定产品编译目标
lunch rk3399_roc_pc_plus-userdebug

# 3. 编译默认的 Launcher 模块（Android 10 默认使用 Launcher3QuickStep）
make Launcher3QuickStep
```

#### 步骤 3：adb 快速推送与数据清理（验证）
编译完成后，利用 adb 将 APK 快速推送到设备，清理缓存使其即时生效，而无需重新打包固件或擦除用户数据：

```bash
# 1. 获取 root 权限并重新挂载系统分区为可读写
adb root
adb remount

# 2. 推送编译生成的 APK 到对应的 product 分区中替换原生桌面
#（注意：Android 10 之后 Launcher3/Launcher3QuickStep 存放在 product 分区中）
adb push out/target/product/rk3399_roc_pc_plus/product/priv-app/Launcher3QuickStep/Launcher3QuickStep.apk /product/priv-app/Launcher3QuickStep/Launcher3QuickStep.apk

# 3. 清理 Launcher 的运行时数据库，以强制桌面重新读取 default_workspace_5x5.xml 配置
adb shell pm clear com.android.launcher3

# 4. 返回桌面即可看到新布局已生效
adb shell input keyevent 3
```
