## 编译环境

我的Ubuntu24.04

1. [安装必须的软件包](https://source.android.com/docs/setup/start/requirements?hl=zh-cn#install-packages)

2. 安装Anaconda
解决`python`版本和环境配置问题。有强大的虚拟环境隔离。

以这次编译的Android10固件为例，其依赖python2.7版本。而我们的ubuntu2404默认是3.13。
那么我们可以使用conda命令来创建一个python2.7的虚拟环境。

```bash
conda create -n python2 python=2.7
conda activate python2

# 列出当前所有的conda虚拟环境
conda env list

conda info --envs
```

3. 全量编译并打包

```bash

# 整体编译支持HDMI+DP显示的公版Android10固件
./FFTools/make.sh -d rk3399-roc-pc-plus -j8 -l rk3399_roc_pc_plus-userdebug

# 把上条命令编译出来的各个镜像打包成统一的更新固件
./FFTools/mkupdate/mkupdate.sh -l rk3399_roc_pc_plus-userdebug

```
`./FFTools/make.sh`的作用：`Firefly`提供的整体编译脚本，自动按顺序编译`U-Boot`, `Kernel`, `Android`

`rk3399-roc-pc-plus`：`Firefly`指定设备树（Devices Tree）和硬件板级配置

`j8`: 使用8个CPU核心并行编译

`rk3399_roc_pc_plus-userdebug`：指定Android源码的`lunch`编译目标。`userdebug`表示带有root权限和调试功能
