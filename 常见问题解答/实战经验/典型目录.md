# ROC-RK3399-PC-Pro Android 10 开发典型目录与重要文件速查手册

在进行 Rockchip 平台的 Android 10 系统底层与应用层深度定制时，以下五个路径是开发者接触最频繁、最重要的“命脉”文件及目录。本手册为您详细拆解其核心作用、实战用途及关联常用指令。

---

### 1. 系统核心资源包（System Core Resources Package）
*   **物理路径**：`out/target/product/rk3399/system/framework/framework-res.apk`
*   **核心功能与解释**：
    *   **作用**：存放系统全局核心级资源（如系统内置图标、多语言字符串 `strings.xml`、整机功能开关 `config.xml` 以及默认全局壁纸等）的编译打包产物。
    *   **其他开发用途**：
        *   **Overlay 机制效果验证**：无需在板子上开机确认，在编译后直接使用 `unzip -l` 查看该 APK 内的 `res/drawable-nodpi-v4/default_wallpaper.png` 即可秒速确诊我们自定义的 Overlay 图片是否已被编译器成功打包覆盖。
        *   **局部增量编译重打**：当修改了 Overlay 资源却由于编译缓存未生效时，可先清理其编译中间缓存再打包：
            ```bash
            rm -rf out/target/common/obj/APPS/framework-res_intermediates
            ```

---

### 2. 统一完整固件输出路径（Unified Firmware Output Image）
*   **物理路径**：`rockdev/Image-rk3399_roc_pc_plus/ROC-RK3399-PC-Pro_Android10_HDMI_260529.img`
*   **核心功能与解释**：
    *   **作用**：经过统一打包脚本（`mkupdate.sh`）生成的全量分发固件。它是引导加载程序（Bootloader）、内核（Kernel）、设备树（DTB）以及各系统分区镜象（`system.img`、`vendor.img` 等）的合集单文件。
    *   **其他开发用途**：
        *   **版本控制与归档**：文件名中的 `HDMI` 代表该固件默认的显示信号输出通道，末尾的 `260529` 是编译时间戳（代表 2026年5月29日），便于在多分支并行开发时确认固件的编译时间和显示通道属性。
        *   **一键生产刷写**：此 `.img` 镜像可以直接导入烧录工具中进行一键擦除、完全刷写或批量出厂烧录。

---

### 3. Linux 平台专属固件升级烧录工具（Linux OS Upgrade Tool）
*   **物理路径**：`RKTools/linux/Linux_Upgrade_Tool`
*   **核心功能与解释**：
    *   **作用**：瑞芯微官方针对 Linux 宿主机（如 Ubuntu 编译服务器）开发的高效命令行升级刷机工具。
    *   **其他开发用途**：
        *   **分区增量刷写（调试利器）**：日常开发中如果不希望浪费时间全量刷固件，可以在编译出单个分区镜像（如修改了壁纸后只编译出的 `system.img`）后，通过该工具实现**“只刷 system 分区”**，调试迭代耗时可缩短 80% 以上！
        *   **自动化测试集成**：由于是命令行工具，可以通过编写 shell 脚本，在编译完成的第一时间自动执行设备检测与静默烧录。
    *   **实战高频指令**：
        *   列出当前通过 OTG 连接的所有板子：`./Linux_Upgrade_Tool LD`
        *   单独更新 system 镜像并自动重启：`sudo ./Linux_Upgrade_Tool DI system /path/to/system.img`

### 4. 自定义壁纸覆盖根路径（Default Wallpaper Custom Overlay Directory）
*   **物理路径**：`device/rockchip/rk3399/overlay/frameworks/base/core/res/res/drawable-nodpi`
*   **核心功能与解释**：
    *   **作用**：在 AOSP 的资源覆盖（Overlay）机制中，该路径与 Framework 系统框架资源的相对路径结构 100% 镜像对应，专门用于存放自定义默认壁纸。
    *   **其他开发用途**：
        *   **DPI 无损显示，避坑 OOM**：使用 `nodpi`（无密度缩放）文件夹可以强制 Android 对壁纸进行 1:1 的原始物理像素渲染。这能有效防止大尺寸图片在适配高像素屏幕时，因 DPI 强行差值计算导致**内存溢出（OOM）**以致系统卡死或 Launcher 崩溃的问题。
        *   **设备级尺寸隔离**：
            *   同级目录 `drawable-sw600dp-nodpi`：适配最小宽度 $\ge 600\text{dp}$ 的平板、手持终端等。
            *   同级目录 `drawable-sw720dp-nodpi`：适配最小宽度 $\ge 720\text{dp}$ 的 HDMI 显示器或车载中控屏等。

### 5. 板级产品核心 Makefile 配置文件（Board Product Makefile Configuration）
*   **物理路径**：`device/rockchip/rk3399/rk3399_roc_pc_plus/rk3399_roc_pc_plus.mk`
*   **核心功能与解释**：
    *   **作用**：当前 ROC-PC-Plus 产品编译链路的核心配置文件，描述了该机型所特有的软件配置、编译依赖以及打包属性。
    *   **其他开发用途**：
        *   **挂载资源 Overlay 路径**：在文件末尾新起一行追加 `PRODUCT_PACKAGE_OVERLAYS += device/rockchip/rk3399/overlay`，即可全局启用并激活您的自定义壁纸替换规则。
        *   **系统预置应用与功能裁剪**：通过对变量 `PRODUCT_PACKAGES` 执行添加或移去操作，决定哪些预装 App（如特定主屏应用、Launcher3 或硬件调试服务）被编译并搭载进入系统镜像。
        *   **硬件驱动及特性定义**：在该文件中声明 Wi-Fi、蓝牙、音效等硬件配置变量，让系统能够顺利加载相对应的设备驱动。

---

### 6. 默认桌面布局配置文件（Launcher3 Default Workspace Config）
*   **物理路径**：`packages/apps/Launcher3/res/xml/default_workspace_5x5.xml`
*   **核心功能与解释**：
    *   **作用**：决定了系统开机首次启动时桌面上预设的图标、快捷方式以及 Widget 的摆放布局。包括桌面的几屏（`screen`）、各个图标所在的网格横纵坐标（`x`、`y`）、底部常驻快捷栏（`Hotseat`）中的应用等。
    *   **其他相关路径**：
        *   3x3 网格配置：`packages/apps/Launcher3/res/xml/default_workspace_3x3.xml`
        *   4x4 网格配置：`packages/apps/Launcher3/res/xml/default_workspace_4x4.xml`

---

### 7. Launcher3 桌面系统 APK 编译产物（Launcher3 Package Output）
*   **物理路径**：
    *   主应用路径（Android 10+ 位于 `product` 分区）：
        *   带手势管理的默认 Launcher：`out/target/product/rk3399_roc_pc_plus/product/priv-app/Launcher3QuickStep/Launcher3QuickStep.apk`
        *   基础 Launcher：`out/target/product/rk3399_roc_pc_plus/product/priv-app/Launcher3/Launcher3.apk`
*   **核心功能与解释**：
    *   **作用**：Launcher3 编译生成的 APK 文件。在 Android 10+ 中，桌面系统作为特权级应用打包输出在 `product` 分区下的 `priv-app` 文件夹。
    *   **其他开发用途**：在单模块编译完成后，可以直接提取该 APK 并通过 adb 推送至设备的 `/product/priv-app/` 对应路径进行快速热替换验证，无需整体固件重新烧录。
