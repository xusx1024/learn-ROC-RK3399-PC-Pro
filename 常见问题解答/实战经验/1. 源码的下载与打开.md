### 下载后合并源码

1. 解压分卷压缩包：这5个文件是连在一起的，只需要用`7z`命令解压第一个，它会自动把后面几个合并解压出来。

```bash
# 解压 .001 文件，它会自动拉取 002-005
7z x Firefly-RK3399_Android10.0_git_20211222.7z.001
```
2. 解压完成后，会得到一个名为`Firefly-RK3399_Android10.0`的文件夹。

```bash
cd Firefly-RK3399_Android10.0

# 恢复代码仓库的初始状态
git reset --hard
```

3. 把更新包打进去
```bash
# 建立软链接，注意路径和点（.）
ln -s /home/wangwu/firefly/3399-pro/rk3399-android10.0-bundle .bundle

# 执行更新，它会把你原来下载的那些 0~10 的补丁包内容合并进来
.bundle/update

# 最后应用所有最新的代码
git rebase FETCH_HEAD

```

4. 使用 `ASFP`（Android Studio for Platform）打开与配置源码

   * **导入项目**：
     启动 ASFP，选择 **Open**，直接选中源码根目录文件夹（如 `rk3399_Android10.0`），等待 IDE 载入并同步项目。

   * **配置 JDK**：
     当 IDE 提示 "Project JDK is not defined" 时，点击 **Setup SDK**。
     * **如何选择**：请选择本地安装的标准 **`Java JDK`**（例如本地检测出的 `Java 17.0.18` 或其他本地 OpenJDK），**不要**选择类似于 `Android API 36.0` 这种公共的 Android SDK。
     * **原因**：系统源码中使用了大量带 `@hide` 标记的内部私有 API。ASFP 本身能自动通过编译产物来关联这些私有 API，我们只需为它提供一个标准的 Java 运行环境作为底座；若选择普通 Android SDK，会覆盖系统的特权 API 索引，导致大面积代码解析爆红。

   * **启用 Git 版本控制关联**：
     网盘下载的源码默认带有 `.git` 文件夹，但 IDE 初次导入时可能没有自动注册。
     * **启用方法**：点击顶部菜单栏的 **VCS**（或 **Version Control**） -> **Enable Version Control Integration...** -> 选项框中选择 **Git** -> 点击 **OK**。
     * 关联后，IDE 将能正常高亮被修改的代码文件，并在文件左侧和底部工具栏显示差异对比。

   * **新建本地分支进行开发**：
     为了将您的修改与原始 SDK 清晰剥离，在修改前必须新建一个本地开发分支。
     * **操作方法**：在源码根目录下执行以下命令新建并切换到开发分支（如 `dev_custom`）：
       ```bash
       git checkout -b dev_custom
       ```
     * **原因**：默认的 `firefly` 等原始分支应作为“干净底座”保留。在独立分支开发时，可以通过 `git diff firefly..dev_custom` 随时查阅自己的修改，也更易于维护和导出 Patch 补丁。
