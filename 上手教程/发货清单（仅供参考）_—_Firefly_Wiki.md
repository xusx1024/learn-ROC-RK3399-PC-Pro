ROC-RK3399-PC Pro

ROC-RK3399-PC Pro 采用 RK3399 六核(A72x2+A53x4) 64 位处理器，主频高达1.8GHz，集成了四核 Mali-T860 GPU，性能优异。

ROC-RK3399-PC Pro 是一款迷你 PC 主板,体积只有小型手机的大小。

![_images/front_interface_en.png](https://wiki.t-firefly.com/zh_CN/ROC-RK3399-PC-Pro/_images/front_interface_en.png)

![_images/back_interface_en.png](https://wiki.t-firefly.com/zh_CN/ROC-RK3399-PC-Pro/_images/back_interface_en.png)

+   Dual-core Cortex-A72 up to 1.8GHz & Quad-core Cortex-A53 up to 1.5GHz
    
+   Mali-T864 GPU – 支持 OpenGL ES1.1/2.0/3.0、OpenCL1.2、DirectX11.1
    
+   LPDDR4 RAM（2/4 GB）
    
+   DC（12V-2A）
    
+   1 x USB 2.0（Type-A 接口）
    
+   1 x USB 3.0（Type-A 接口）
    
+   10/100/1000 Mbps 以太网接口
    
+   IR 红外遥控模块
    
+   3.5mm 耳机接口
    
+   1.25 mn 风扇接口（12V)
    
+   HDMI 2.0a with HDCP 2.2（支持 4K@60 Hz）
    
+   1 x Type-C（Type-C0 支持 DisplayPort 1.2（支持 4k@60 Hz）、USB 3.0）
    
+   3 x MIPI (MIPI0 仅支持 DSI、MIPI1 支持 DSI 或 CSI、MIPI2 仅支持 CSI，且 DSI 最大支持 1080P@60fps）
    
+   1 x eDP 1.3（最大支持 2K@60fps）
    
+   WIFI（支持 2.4G/5G Hz 频段）
    
+   BT（支持 蓝牙 5.0 BLE）
    
+   MicroSD（TF）卡槽
    
+   M.2 PCIE-M.key 接口
    
+   60 个扩展接口（支持 I2C、SPI、Uart、I2S、Line\_in/out、SPDIF 等接口）
