# ROC-RK3399-PC Pro 学习与实战开发手册 🚀

欢迎来到 **ROC-RK3399-PC Pro** 开发板的学习与实战仓库！本项目旨在为开发者提供全面、结构化的嵌入式系统编译、烧写以及调试指南。

---

## 📢 项目重要声明

1. 📖 **文档来源与排版说明**
   本项目中的绝大部分开发文档（如 Android/Linux 编译、驱动开发指南、硬件配置等）均是从 **Firefly 官方发布的 HTML 官方文档** 抓取、解析、并精心转换成 **Markdown (MD)** 格式保存在此处的。此举是为了提供更加优雅的离线阅读体验、支持全局关键字极速检索、以及方便个人进行增量标注。**更重要的是，结构化的 Markdown 格式对 AI 极其友好，非常利于同 AI 编程助手（如大语言模型、智能代理等）进行高精度的上下文深度交互与智能问答，极大提升了利用 AI 辅助嵌入式开发和排卡调测的效率。**

2. ✍️ **核心实战心得与个人笔记**
   项目根目录下的 **`常见问题解答/实战经验/`** 目录是本仓库最宝贵的部分。这是作者本人在深入研究 RK3399-Pro 平台期间，所记录的**第一手实操笔记、避坑经验与调试心得**。
   * 这里真实记录了各种编译与烧写时的隐蔽 bug（例如 Ubuntu 24.04 编译环境与 Python 2.7 冲突问题、`upgrade_tool` 跨版本升级导致的 `Download Firmware Fail` 报错、`sudo` 沙箱下主目录访问限制等）。
   * 记录了针对 Rockchip 平台进行系统级和应用级定制（如预置系统级/用户级免配置 App）的底层原理解析。
